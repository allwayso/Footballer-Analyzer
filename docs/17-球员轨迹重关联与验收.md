# 球员轨迹重关联与验收

更新：2026-10-20。算法版本：`pitch-relative-v1`。

**当前交付是本地工程实现，精度与数量验收未通过。** 已接入追踪后身份关联、旧运行分析、推荐确认、自动／手动历史、撤销与过期处理。固定85分钟素材初测为128条片段自动减少到116组，未达到64组目标；128条身份真值仍待独立人工标注。参数为工程初值，尚未完成开发集调优和正式冻结。

## 1. 坐标与整体流程

按本次确认，第一版不实现背景特征匹配或额外相机运动补偿：

1. 优先使用经过人工确认、端点投影有效的**球场坐标**，距离为米、速度为米每秒。
2. 动态白线标定还须覆盖断点缺口，至少三名共同可见球员的投影连续，不能只凭 `reviewed: true` 放行。
3. 缺少可靠投影时，使用至少三名持续共同可见、相对布局稳定的球员作参照，优先邻近者、最多八名。以参照中心描述相对位置，并按人物高度归一化。该数值不作为米制距离。
4. 两种坐标均不可靠时，不构造该候选。共同参照发生布局突变时拒绝自动关联；这不是完整的镜头切换检测器。

ByteTrack 保留原编号。关联层连接原始片段，生成单视频内的融合组，不改写 `tracks.parquet`、检测缓存、球员档案或跑动报告。稳定节点由原始轨迹号和首个真实源帧确定；同号超长缺口另建节点。原始节点到场内记录须唯一映射，关联断点必须对应真实场内观测，否则不自动套用。

新运行逐帧积累真实观测和颜色，使用最近约15秒观测每两秒分析一次。等待前驱超过 ByteTrack 丢失缓冲、后继具备至少一秒证据后建立临时组。临时结果写入 `association_live.json`；追踪结束用完整输入重新分析，只把复核通过的边写入正式历史。历史记录其来源为追踪中决定或追踪后补充，不把临时组直接当作最终身份。

旧运行在独立 `/field-review` 页面点击“分析轨迹关联”，复用原视频和追踪缓存，无需再运行检测。颜色缓存与新运行采用相同采样规则。

## 2. 评分和安全条件

取前段末尾、后段开头各最多一秒真实观测，用成对斜率中位数估计速度，再以中位数估计端点与残差。向前预测前段、向后验证后段，采用两侧较大的位置误差。急停、变向、片段过短、投影跳变会影响分数或禁止自动执行；没有专门姿态网络。

位置、速度、缺口分量按 `0.68 / 0.27 / 0.05` 组合，再由多帧上衣颜色作辅助折减。每秒最多采样五帧，每侧至少两帧颜色特征才有效。同队同色不能单独触发自动融合。关联分数表示证据强弱，**不是身份正确概率**。

| 参数 | 当前工程初值 | 含义 |
|---|---:|---|
| 最高阈值 | 0.88 | 严格大于，且所有安全条件满足，才自动融合 |
| 最低阈值 | 0.50 | 严格大于才保留推荐；等于最高阈值只推荐 |
| 竞争分差 | 0.08 | 来源、目标双方相对次优候选均须领先 |
| 自动最大缺口 | 3秒 | 球场坐标模式的上限 |
| 推荐最大缺口 | 10秒 | 超出不进行运动外推关联 |
| 端点窗口 | 1秒 | 只取真实观测，不补漏检帧 |
| 最低观测要求 | 每侧5次、跨度至少0.16秒 | 不足时不能自动执行 |
| 位置基础尺度 | 0.65米 | 叠加缺口不确定性和拟合残差 |
| 速度差尺度 | 4米/秒 | 速度一致性评分的尺度 |
| 最大合理速度 | 12米/秒 | 可达性与突跳过滤，不作为跑动统计结论 |
| 颜色距离上限 | 0.65 | 明显异色禁止自动执行 |

邻近参照模式额外要求缺口不超过0.6秒、位置误差更严格且具备多帧颜色证据。这些参数和特征开关定义于 `AssociationConfig`，完整快照、版本、摘要随每次分析保存。当前无页面调参入口；修改参数后必须重新分析。

自动执行同时要求互为最佳可用候选、足够竞争分差，以及允许“不匹配”的一对一分配。每合并一条就重新计算当前组之间的竞争。每次检查整个组的原始时间范围，拒绝同时存在不同真实观测的组合；融合长链不用于增强后续评分。撤销阻止关系也检查整个组，不能借第三片段间接重新连接。

高于最高阈值但未通过安全约束的对象仍可能作为人工推荐，分数高不保证自动执行。

## 3. 校对页面与历史

原视频在上，场内片段和操作历史在下，保持独立页面。首末帧点击仍跳到真实观测、加深所选行，并用鲜红粗框标记所选轨迹；未选择时没有红色选中框。

- “分析轨迹关联”显示阶段、进度、失败原因与重试；刷新恢复状态，服务重启时未完成任务转为失败。
- “可能融合对象”按当前融合组提供最高分对象，显示目标首末帧和关联分数，可定位并确认；同组不再推荐。
- 确认推荐记为“手动执行”；原来的目标帧弹窗并入方式保留。
- 历史区分“自动执行／手动执行”。自动项保存分数、实际竞争分差、全部阈值、算法版本、证据摘要、输入摘要、分析批次和执行阶段。
- 支持逐项撤销和某批自动项撤销，批次撤销保留手动项。撤销自动项默认阻止该关联再次自动恢复；可解除阻止后重新分析。
- 显示原始片段数、当前独立组数、自动减少组数；最后一项按手动历史形成的组数与最终组数之差计算，不统计“参加融合的记录条数”。

旧历史缺少 `execution` 时按手动读取。原记录标识保留。视频、轨迹、标定或参数变化会使旧自动项暂停生效，旧推荐隐藏；手动项继续按现有有效性规则读取。计算期间输入变化则拒绝发布，并保留上一份结果。自动历史和分析结果作为同一份 JSON 原子写入，避免只保存一半。

### API 与产物

以下路径均以 `/api/runs/{run_id}` 为前缀：

| 方法 | 后缀 | 用途／请求字段 |
|---|---|---|
| POST | `/association` | 启动后台分析，空对象即可；运行中重复请求复用任务 |
| GET | `/association-job` | 任务状态和进度 |
| GET | `/association` | 当前推荐、过期状态、组数摘要 |
| GET | `/association-result` | 最新原始分析快照及状态 |
| POST | `/association-confirm` | `record_id`、`batch_id`，确认当前推荐 |
| POST | `/field-merge-undo` | `operation_id`，撤销一项 |
| POST | `/association-batch-undo` | `batch_id`，撤销一批自动项 |
| POST | `/association-unblock` | `pair`，解除一条阻止关系 |

`field_review.json` 保存历史、分析和阻止关系；`association_job.json` 保存任务状态；`association_evidence.json` 保存带视频／轨迹摘要的多帧颜色缓存。页面末帧沿用原有“最后真实观测帧”的闭端含义；视频处理范围和身份绑定仍使用右开区间，不混用。

| 有效场内片段 | 128条，保持原分段和标定范围 |
| 视频 SHA256 | `27678207cb3097a82a90b1f5795f02865d29fedec88bfc05f68a86aa8dc08ba2` |
| 本地独立副本 | `outputs/reassociation_acceptance_v1/run_20261016T033403_60e13f22` |

原运行只读，验收副本不复制已有融合历史。`benchmark_input.json` 保存输入摘要和完整片段清单；`identity_truth.json` 中全部128条当前为未知。不得删短片段、修改场内范围或改变拆分规则缩小分母。

在安装了本项目依赖的环境执行：

```powershell
$env:PYTHONPATH='src;tests;scripts'
# destination 必须为新的目录；已有目录不会覆盖。
python scripts/evaluate_reassociation.py freeze outputs/run_... --destination outputs/association_check/run_...
python scripts/evaluate_reassociation.py analyze outputs/association_check/run_...
python scripts/evaluate_reassociation.py gallery outputs/association_check/run_... --review-base-url http://127.0.0.1:8778
python scripts/evaluate_reassociation.py ablate outputs/association_check/run_...
# 完成人工真值后重新执行，生成逐边及组级验收报告。
python scripts/evaluate_reassociation.py evaluate outputs/association_check/run_...
```

`analyze` 拒绝有既有融合的验收副本。没有经确认的有效场内片段时，固定基准和消融会报错。`parameters_frozen.json` 保存本次参数快照，当前状态明确为 `provisional-uncalibrated`，文件名不表示已完成开发集调优。

## 5. 实测结果与验收判定

未针对85分钟素材降低阈值。当前工程初值一次完整分析用时16.392秒，含颜色采样和候选分析，不含融合提交，也不是整段检测或在线追踪耗时。

| 指标 | 当前结果 | 判定 |
|---|---:|---|
| 原始片段 → 自动后组数 | 128 → 116 | 未达到≤64组 |
| 自动边／自动减少组数 | 12／12 | 减少9.375% |
| 原始候选数 | 60 | 不等于正确关联数量 |
| 不同第一推荐／有推荐记录 | 31／35 | 一个组可对应多行 |
| 已完成独立身份标注 | 0／128 | 精度无法确认 |
| 自动边与组内身份对准确率 | 待人工真值 | 未通过 |
| 推荐第一名准确率、剩余正确关联覆盖率 | 待人工真值 | 未通过 |

`acceptance_report.json` 当前把全部未知边按“未正确”计入，因此 `edge_precision: 0` 是严格验收下界，不能解释为已证明12条融合全部错误。报告列出所有逐边结果和受污染或未确认的组；独立完整真值缺失时不会通过。

同一输入的消融结果如下。耗时不含缓存颜色采样，各项只运行一次，不能用于严谨性能排序；数量变化也不能证明精度贡献。

| 配置 | 自动后组数 | 减少组数 | 候选数 | 秒 |
|---|---:|---:|---:|---:|
| ByteTrack基线 | 128 | 0 | 0 | 0.461 |
| 位置 | 124 | 4 | 49 | 6.996 |
| 位置＋运动 | 116 | 12 | 51 | 4.712 |
| 再加邻近参照 | 116 | 12 | 61 | 12.086 |
| 再加颜色 | 116 | 12 | 60 | 12.048 |

另尝试的 `run_20261017T141433_15bc97dc` 没有经人工确认的有效场内片段，不能作为有效开发集，也没有据此完成调优。未擅自将其标定改为已验收。

正式验收仍采用以下标准：

1. 全部自动融合边中正确比例≥99%，未知边不计正确；全部融合组内跨片段身份对正确比例≥99%，列出全部受污染组。
2. 仅靠自动执行将128条输入降至64组或以下，人工融合不计入。
3. 推荐第一名准确率≥90%，报告推荐数量、正确推荐数量和剩余正确关联覆盖率。
4. 在其他素材完成调参后冻结配置，再独立验收85分钟素材。若根据其错误继续调参，须补充未参与调参的新素材验证。

准确率优先，两项硬指标未同时达到即未通过，不降低阈值凑数量。当前尚缺完整人工真值、有效开发集调优及独立冻结验收，不能宣称方案达到目标。

## 6. 工程验证与边界

已运行完整76项回归并通过；最后的小补丁另运行追踪与重关联17项，全部通过。前端 JavaScript 语法检查通过。测试覆盖方向优于静态最近位置、同队交叉竞争、急停／短片段保守处理、相对参照平移缩放和布局突变、动态投影失效及跳变、整组冲突、间接阻止关系、在线关闭等待及末尾复算、幂等撤销、输入过期、旧历史兼容、后台任务失败重试与独立真值门禁。

浏览器实操核对了分析、推荐确认、自动／手动历史、刷新恢复、逐批撤销保留手动项、重算阻止重合、解除阻止、首帧定位和红框选中。真实副本页面核对了128／116／12摘要、源帧750跳转、推荐和自动历史。校验均在隔离副本，原8766服务与原始轨迹保持不变。

仍有以下限制：

- 运动模型适用于短缺口，十秒以内推荐也不保证可辨认；同队交叉、变向、重复检测和邻近参照自身运动可能造成歧义。
- 端点跳变检查不能发现所有片段内部平滑串号，必须做完整人工身份检查。
- 球场投影的连续性不等于独立几何精度合格；固定映射在相机运动后仍可能失效，不能仅凭“已验收”状态保证安全。
- 没有独立镜头切换网络，连续性检查只能保守拒绝部分异常；没有姿态网络或跨视频身份模型。
- 尚未重新运行真实素材的完整检测＋在线关联来证明速度和精度。在线有限窗口结果是临时结论，最终以完整复核为准。
- 新运行完成后如果再修改或确认标定，输入摘要会改变，须在校对页重新分析；本功能不自动创建球员身份绑定或重算跑动报告。

主要实现：`reassociation.py`（证据与融合）、`stream_association.py`（在线临时组）、`field_review.py`（原分段与历史）、`association_evaluation.py`（固定分母评估）、`scripts/evaluate_reassociation.py`（复现工具）。
