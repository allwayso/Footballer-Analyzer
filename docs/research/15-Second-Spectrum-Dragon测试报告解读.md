# Second Spectrum Dragon 越位技术测试报告解读

> 历史调研归档：厂商信息与项目能力描述保留调研时口径；当前实现与验收状态见[验证文档](../validation.md)。

> 整理日期：2026-10-19<br>
> 报告：FIFA Test Report - Offside Technology，Genius Sports SS, LLC，报告编号 129247，2023 年 7 月版<br>
> 本文性质：对用户提供的测试报告作中文摘要，并讨论其对 FootballerAnalyzer 的参考价值；不是对 Second Spectrum 内部算法的逆向结论。

## 一、结论

这份报告对本项目有参考价值，重点在于**如何定义系统级测试、建立独立真值、按空间位置和困难情境拆分误差，并保留人工复核环节**。它不能说明 Second Spectrum 使用了哪种检测器、跟踪器或 ReID 模型，也不能证明本项目能达到报告中的精度。

报告覆盖的是安装在体育场内的 12 摄像机半自动越位系统。它结合越位几何、三维骨骼和球跟踪、踢球时刻检测、告警逻辑与比赛情境进行测试。与本项目现有的单视频人物轨迹和二维场地投影相比，采集条件、输出维度和任务目标均不同。

## 三、主要测试内容与结果

### 越位线与坐标

越位技术部分测试二维和三维越位场景中的线放置，并检查标准越位线展示、三维裁判坐标，以及人工选择和自动选择坐标相对于标准数据集的结果。报告列出的各项测试均为 PASS。

### 骨骼追踪

报告列出 19 个评估身体点，包括左右肩、髋、肘、腕、膝、踝、额头、后脑和大脚趾，以及头部点。测试以 Vicon 作为参考，按空间误差评估：

| 评估项 | 报告门槛 | 报告结果 |
|---|---:|---|
| X、Y、Z 合成差异 | 小于 0.15 m | PASS |
| 所有地标的 X、Y、Z 平均差异 | 小于 0.10 m | PASS |
| X 轴平均差异 | 小于 0.10 m | PASS |

报告指出，X 分量是越位判罚的关键方向。这里体现了一个重要测试原则：除了整体空间误差，还要单独检查对目标任务最敏感的轴向误差。

### 球追踪

二维球追踪部分展示了球场已知位置与系统位置之间的差异分布图。图例中的点大小对应约 0.15 m、0.20 m 和 0.25 m 的位置差异。报告没有在该页提供汇总均值、百分位数或最大误差，因此不应把图上的点概括成全场平均精度或最差精度。

### 踢球时刻、告警和比赛情境

- 系统可自动识别踢球时刻，报告称通常在真实时刻的 2 帧以内。
- 越位场景能够触发告警；球员 X 坐标差距小于 1 m 时提示“接近越位/接近不越位”，差距更大时只提示“明显越位”。
- 比赛情境测试中，系统基本能按足球规则运行；但多数情况下，操作员仍需要把自动检测的踢球时刻向前调整，最多约 2 帧。
- 报告记录了高密度球员、多次触球或轻触、滚地传球、对方球员未标记或错标、场外球员等困难情境。
- 报告明确指出半自动越位系统需要人工参与判读；球场设计、机位和照明会影响实际表现，赛事组织方应在自己的环境中测试。

## 四、对 FootballerAnalyzer 的启发

### 1. 验收应测完整链路，而不只看检测框

本项目已有原始检测、带 ID 轨迹、场地投影、身份绑定和报告生成等分层产物。可以沿用这种边界，分别测漏检、轨迹身份连续性、投影误差和最终距离误差，避免单一“检测准确率”掩盖下游问题。

### 2. 建立小规模人工真值集

选取数段有代表性的短片，人工标注抽样帧中的球员脚点、轨迹 ID 和球场坐标。把这些人工数据独立保存为验收参考，不参与算法拟合，再对照系统输出。验收集应覆盖近、中、远区域，以及遮挡、交叉、快速移动和画面边缘等情况。

### 3. 按空间区域和误差来源拆分结果

报告用全场位置图呈现球追踪误差。本项目也应按球场区域统计像素或米制位置误差，并同时报告标定误差和跟踪误差。这样能判断误差集中在远端、边线、禁区还是轨迹断裂处，而不是只得到一个全片均值。

### 4. 将身份切换作为独立质量项

当前项目已知限制包括漏检、断轨和换 ID。建议在人工验收片段上统计 ID switch、轨迹覆盖率、断轨次数和错误合并，并以困难情境分组。自动 ReID 或 tracklet 合并上线前，先验证这些指标是否改善，且不能以错误合并换取表面上的轨迹变长。

### 5. 把人工复核纳入产品流程

报告承认踢球时刻需要人工修正，并把操作员视作系统的一部分。本项目已有逐帧检查、身份区间编辑和报告重算流程，可进一步把不确定帧或疑似身份切换做成待复核项，并保留修改前后的结果与依据。

## 五、不能直接类比的部分

1. **三维骨骼精度不等于二维球员位置精度。** 报告的 0.10–0.15 m 指标来自 12 摄像机和 Vicon 参照下的三维身体关键点测试；本项目主要把二维画面脚点投影到场地平面。量测对象、传感条件和误差来源均不同。
2. **系统级认证结果不说明具体算法。** 报告没有公开模型结构、检测器、跟踪器、外观特征或相机融合细节，不能据此断言其采用某种网络或关联方法。
3. **测试通过不代表所有比赛场景均无误。** 报告本身记录了密集、多触球、错标和场外球员等困难，也要求在具体安装环境中测试。
4. **图表不等于完整统计报告。** 球追踪页给出位置差异示意，但没有完整的样本数、平均值、分位数和最大值，不能据图例宣称精度上限。

## 六、建议的本项目验收记录

建议先对 3–5 段短片建立人工参考，形成统一的验收表：

| 维度 | 建议记录 |
|---|---|
| 检测 | 人工可见人数、检测人数、漏检/误检；按近中远区域分组 |
| 跟踪 | ID switch、断轨、轨迹覆盖率、错误合并；注明遮挡与交叉情境 |
| 标定与投影 | 独立参考点误差、中位数与高分位误差、失败帧比例、空间区域 |
| 距离统计 | 对照人工校验轨迹计算的距离误差；注明有效观测时长和缺失区间 |
| 复核成本 | 每分钟需要人工修正的帧数、身份区间数和标定点数 |

这些是建议的测量维度，不是已通过的项目指标。具体阈值应在确认目标用途和建立参考数据后再定，不能直接照抄该认证报告的骨骼追踪门槛。
