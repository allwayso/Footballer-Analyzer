## 历史实片结果

以下保留原 README 的实测数据，用于复现与对照，**不是本次文档改动后重新执行的评测**。

| 项目 | 记录 |
|---|---|
| 输入 | 1080p、25 FPS、125 帧，5 秒真实素材。 |
| 1280 修复版 | 3,545 条追踪观测，约 16.9 秒。 |
| 1920 精度版 | 4,106 条追踪观测，约 27.0 秒。 |
| 耗时口径 | 含分队预采样与产物输出，不含 Python 启动导入。 |
| 人工抽样 | 五帧共 105 人次，旧配置关联观测 44 次、精度版 103 次，仍有 3 次抽样编号变化。 |

这些数字不能换算为完整视频的身份准确率、长期稳定性或整场跑动误差。准确率需要固定输入、身份真值和独立评估；观测数也不等于人数。

固定镜头历史案例 `clip_70m00s` 保存过第 147 帧四点标定草稿，首、中、末帧可持续投影，人物缓存不变。但素材球门与 JFA 预设有差异，独立门柱参考点误差约 40 / 23 px，尚未通过全场几何精度验收。详见文档 `14`；拟合残差不能代替独立点误差。

## 自动化检查

测试覆盖源时间与采样、缺口切段、身份冲突、报告快照与版本隔离、标定几何、真实视频末尾和 HTTP 边界。人工复核相关检查位于 `tests/test_field_review.py`。完整命令见 [开发与贡献指南](../CONTRIBUTING.md)。

原 README 记录的“42 项测试通过”是历史状态，不作为持续更新的质量徽章。合成数据测试证明计算与状态约束，不证明真实比赛的识别或测距精度。

## 当前边界

- 检测默认使用 CPU；可选 GPU（需安装 CUDA 或 ROCm 版 PyTorch）。历史吞吐仅适用于对应机器、配置、片段和推理设备，CPU 与 GPU 结果不可直接互比，请用 `benchmark` 在同一协议下对照。GPU 精度为"统计口径一致"（实测按 IoU 匹配 98.9% 的检测框一一对应），不是逐位相同。
- 视频要求恒定帧率。远端小人、遮挡和交叉仍可能漏检、断轨或换 ID；颜色分组不等于可靠身份识别。
- 逐帧白线标定面向白线清晰的连续战术镜头；严重遮挡、近景和切镜的全面支持尚未验证。
- 固定镜头已支持手动标定，但实际尺寸、畸变及场地模型差异仍影响距离。±10% 距离误差尚未独立验证。
- 报告只统计可靠区域内的连续有效观测，缺口不插值，累计值不外推为整场表现。
- 已实现运动颜色在线跟踪与后置轨迹关联，但不等于跨视频身份识别或经过独立验收的 ReID。足球检测／追踪可单独复核，尚无球速、控球／传球事件、多摄融合或对外实时服务。
- 本地 HTTP 工作台用于单机复核，数据库、多租户和对外任务队列不属于当前实现。

## 如何复查

使用实际运行目录替换占位路径；参考 JSON 必须与源素材匹配。

```powershell
& .\.venv\Scripts\python.exe scripts/review_tracking.py --run outputs/run_... --reference configs/tracking_review_demo.json
& .\.venv\Scripts\python.exe scripts/review_pitch_calibration.py --run outputs/run_... --reference configs/calibration_review_barca.json
& .\.venv\Scripts\python.exe scripts/review_manual_calibration.py --run outputs/run_...
```

提交新结果时记录视频摘要、源帧区间、配置、运行编号、耗时口径及人工真值来源；同时保留失败区间和错误实例。第三方比赛画面证据默认只保存在本机，不随公共仓库发布。
