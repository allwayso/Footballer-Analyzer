## 导出

在包含当前功能的项目工作区，使用既有虚拟环境和 FFmpeg：

```powershell
$env:PYTHONPATH = (Resolve-Path .\src).Path
& D:\FootballerAnalyzer\.venv\Scripts\python.exe scripts/export_static_demo.py `
  --run D:\FootballerAnalyzer\outputs\run_20261020T110206_ca1f3de5 `
  --report D:\FootballerAnalyzer\outputs\run_20261020T110206_ca1f3de5\reports\report_viz_20261020T120101_e9eb8ffe `
  --output D:\Footballer-Analyzer-Demo-next
```

输出目录必须不存在。修改标注后先生成新的跑动可视化报告，再选定它导出。工具核对完整输入快照、融合口径、源视频和报告摘要；结束时再次比较输入，变化则拒绝发布。失败包会保留用于诊断，不应发布。

只发布生成的展示包，不能把原始运行目录、输入快照或模型复制进公开仓库。`input-hashes.json` 只包含摘要。绑定和投影已落实到逐帧展示数据，原始文件不会改写。跑动统计直接复用指定报告，不跨缺口补点或补距离。

## 发布与更新

独立演示仓库由 `.github/workflows/pages.yml` 发布，Pages 来源设置为 GitHub Actions。导出新目录后，将其展示文件和 `frames` 同步进演示仓库，检查 `EXPORT_FAILED.txt` 不存在、输入无变化、界面正常，然后提交并推送。不要只换视频而保留旧数据。历史包可保留在本地，公开仓库只保留本次选定素材。

三个页面是 `index.html`、`review.html`、`motion.html`；资源链接均为相对路径，支持仓库子路径。URL 参数包含源帧和人工人物身份；校验页额外保留片段与原始轨迹选择。播放使用视频时间，暂停/逐帧使用 JPEG。快速跳转使用请求序号抑制旧图回写；相邻帧预取有界，缓存最多六张，不预下载整段图片。

## 离线备用

解压完整 ZIP 后可直接打开 `index.html`（数据使用本地脚本加载），推荐双击 `preview.cmd`。一键入口需要现场电脑已有 Python 3，自动选择空闲回环端口，不影响现有的 8778 项目服务；关闭预览窗口即可停止。可以直接打开 `motion.html` 查看独立统计。离线包不需要模型、GPU、虚拟环境或推理后端。

## 数据口径与限制

- 当前素材为 `barca_girona_25m00s`，源帧 `[0,1503)`，25 FPS，60.12 秒。
- 原视频为 1920×1080，展示视频和帧图为 1280×720；框按画布比例缩放。
- 当前 20 个人物身份：19 名球员和1名裁判；34条场内片段、33个有效融合组；45条全画面原始轨迹。这里没有使用旧85分钟素材的128条基准。
- `barca_10` 按有效人工融合继承轨迹36；源帧702同人物重叠优先显式绑定轨迹5。原始框仍可复查，重叠观测不重复计入跑动。
- 人物分组按人工名字前缀显示；保留原始球队标签，不猜球衣号、进攻方向或足球事件。
- 页面均标记演示数据和只读结果。米制精度尚未独立验证，不能把这60秒外推为整场。
- 公开站可在不连接本机的设备访问；实际第二台物理设备和现场网络仍应由展示者提前试开。
