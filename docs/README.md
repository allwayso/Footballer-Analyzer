## 四、阶段边界

`00–03` 与 `10–12` 保留调研结论，`05` 是需求来源，`06` 保留范围分析，`04` 记录已定选型；其中较早的“素材阻塞”“设计尚未开始”描述应结合后续文档阅读。

**当前设计集中在 `07`，实现与验收记录在 `08`**：参数初值仍需独立参考实测，±10% 精度尚未验证。

Python 包、CLI、报告工具和本地浏览器调试台已实现；本地 HTTP API 只服务于人工复盘。数据库、对外部署、多租户与任务队列不在最小闭环范围内。更早的架构草案可从 git 提交 `ce51379` 追溯。
