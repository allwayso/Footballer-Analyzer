# 商业计划书

> 商业规划草稿，保留原稿供讨论。定价、市场规模、整场外推、产品能力与精度陈述尚未逐项核验，不作为当前项目验收结论或服务承诺；当前能力与证据见[验证文档](../validation.md)。

## 执行摘要

**用一台普通摄像机和一台没有独立显卡的笔记本，把一场足球比赛录像变成可核查的球员与足球数据。**

职业级球员追踪系统（Veo、Spiideo、Pixellot、TRACAB）面向顶级俱乐部与联赛，硬件 $1,999 起再加订阅。青少年培训机构、校园足球与业余联赛既付不起、也用不上。

我们交付的是**单机位、低算力、可复核**的替代方案：

- **球员追踪**：在真实西甲战术机位素材上，60 秒内 1,503 帧检出 **63,740 个球员观测（42.4 个/帧）**，45 条原始轨迹经人工校对融合为 **20 个稳定球员身份**，轨迹窗口覆盖率 **94.5%**，人均跑动 **103 米/分钟**（折合 90 分钟约 9.2 公里，与真实比赛吻合）。
- **足球检测**：专用球检测模型 + 跨帧时序筛选，切片模式下已核对帧命中率 **98.6%**（保守口径 96%）——通用检测模型在该任务上完全不可用，这是我们自己啃下来的模块。
- **工程完整度**：**46 项自动化测试**通过；逐帧白线标定、遮挡与末帧处理、换号修复、人工校对与可撤销融合全部落地。**47 次提交、9 条分支、7 个已合并 PR**。

**定价：单场报告 100 元，年费 2,000 元（含 20 场）。**

## 一、问题：谁付不起职业级数据

| 对象 | 现实困境 |
|---|---|
| 青少年培训机构 | 教练需要球员跑动与体能分布，但职业级系统年费 + 硬件投入超出单机构预算 |
| 校园足球 | 有场地、有比赛、有摄像机，但没有把录像变成数据的手段 |
| 业余与半职业联赛 | 想要个人集锦与体能数据，预算只有"一台相机 + 一台电脑" |

**现有方案解决不了，不是技术不行，是成本结构错配**：商用系统卖"硬件 + 订阅"，交付的是高精度坐标与骨骼追踪（对标 FIFA SAOT 标准）；而目标客户真正要的只是"这名球员这场跑了多少米、冲刺几次、活动在哪个区域"。

能力过剩 + 价格过高，中间这一大块市场目前是空的。

## 二、方案

### 2.1 产品形态

单机位固定摄像机 + 普通笔记本，离线处理，输出可核查的球员跑动与足球轨迹报告。

```
视频输入 → 球员检测 → 多目标跟踪 → 人工身份绑定 → 逐帧场地标定 → 米制指标
                                    ↘ 足球专用检测 → 跨帧时序筛选 ↗
```

### 2.2 三个关键设计

| 设计 | 我们怎么做 | 价值 |
|---|---|---|
| **人工初始化身份** | 上场时把轨迹绑定到球员档案，之后保证跟踪不丢；提供独立校对页与可撤销融合 | 绕开最贵的自动 ReID，同时保证身份准确 |
| **逐帧白线标定** | 自动识别球场白线，逐帧解算单应性，强光下单独处理 | 镜头有轻微移动也能保持米制准确 |
| **观测与估计分离** | 观测到的点与模型推断的点分开标记，缺口不插值 | 教练能判断哪个数字可信 |

### 2.3 技术栈

| 环节 | 选型 | 状态 |
|---|---|---|
| 球员检测 | YOLOv8n + COCO 预训练（零训练） | ✅ 42.4 观测/帧 |
| 多目标跟踪 | ByteTrack + 低分检测保留 + 重复框合并 | ✅ 覆盖率 94.5% |
| 身份纠错 | 人工校对页 + 可撤销融合 + 冲突检查 | ✅ 已上线 |
| 分队 | 上衣 HSV 主色 + KMeans(2) | ✅ 已接入 |
| 场地标定 | 逐帧白线几何 + 单应性 | ✅ 已实现 |
| **足球检测** | **专用球模型 + 640 切片 + 跨帧束搜索筛选** | ✅ **98.6%** |
| 坐标 | 米制 105×68 + Parquet | ✅ 已实现 |
| 推理 | PyTorch CPU（默认）/ PyTorch CUDA（可选） | ✅ 已上线并实测；RTX 4060 人物 2.11× / 足球 2.59× |

## 三、为什么是现在

1. **检测模型白菜化**：COCO 预训练 YOLOv8n 零训练即可在足球素材上稳定检出 **42.4 个观测/帧**，把"从零训练检测器"这一最大成本项消掉了。
2. **GPU 加速已落地**：产品路径为 PyTorch CUDA（用户只需装 NVIDIA 驱动，无需 CUDA Toolkit），本机 RTX 4060 实测单帧人物检测 160.2 ms → 14.1 ms。核显方案（AMD ROCm）因需每台机器单独安装 ROCm 驱动而未作为主路径，仅在文档中记录。
3. **基层足球基数已成型**：足协 2025 年数字年报显示业余球员 **979,544 人**（同比 +478,027），社会足球赛事 **4,324 项**，县域联赛球队 **9,890 支**。需求侧已经起量，供给侧还没有对应价位的产品。

## 五、商业模式

### 5.1 定价

| 方式 | 价格 | 说明 |
|---|---|---|
| **单场报告** | **100 元/场** | 客户上传录像，我们出报告 |
| **年度套餐** | **2,000 元/年** | 含 20 场，超出部分按 100 元/场 |

**年费与单场价严格自洽**：2,000 ÷ 100 = 20 场，客户可以清楚判断自己该买单场还是年包。这个价格带与可支付意愿（2,000 元/年）完全匹配，也是商用系统订阅费的一个零头。

### 5.2 为什么先做按场收费

1. **客户零门槛**：不需要买硬件、不需要装软件，上传录像即可。
2. **风险可控**：精度受机位与场地条件影响，单场交付把不确定性隔离在单场内。
3. **持续积累数据**：每交付一场就多一份真实素材，用于补齐精度验收——这是我们最需要的资产。

### 5.3 单位经济模型

| 项目 | 数值 |
|---|---|
| 处理耗时（90 分钟录像，CPU） | 约 3.8 小时；抽帧 1/3 约 1.1 小时 |
| 人工介入（身份绑定与校对） | 约 5–10 分钟/场 |
| 单场边际成本 | 主要为算力与人工，单场 100 元的定价在批量交付下具备正向毛利空间 |

## 六、竞争与壁垒

### 6.1 竞争格局

基层足球数据市场目前没有"买得起"的产品：职业级光学追踪（TRACAB、Second Spectrum）精度极高但部署在顶级场馆；商用整机（Veo、Spiideo、Pixellot）面向俱乐部与联赛，硬件加订阅；开源方案多是演示级代码，没有交付能力。**中间这一档——只要跑动数据、预算几千元的青训与业余市场——是空的。**

### 6.2 与商用方案的可量化对比

| 对比项    | Veo              | Spiideo          | Pixellot                     | **我们**                    |
| ------ | ---------------- | ---------------- | ---------------------------- | ------------------------- |
| 硬件投入   | 专用相机约 **$1,999** | 专用相机 + 多机位（机构报价） | 专用相机（机构报价）                   | **0 元**（用客户现有手机/相机）       |
| 收费方式   | 硬件 + 按月订阅（分档）    | 机构年费报价           | 订阅 + 单场分析计费                  | **单场 100 元 / 年费 2,000 元** |
| 单场数据成本 | 数据分析需另购插件        | 数据模块另购           | **约 $55/场**（官方口径：6 场价值 $330） | **100 元/场（约 US$14）**      |
| 部署门槛   | 需架设专用相机 + 账号体系   | 多机位安装与调试         | 专用相机 + 云端账号                  | **任意单机位 + 一台普通笔记本**       |
| 算力归属   | 厂商云              | 厂商云              | 厂商云                          | **本地 CPU / 核显**           |
| 持续性支出  | 订阅费按年            | 订阅费按年            | 订阅费按年                        | 无强制订阅                     |
| 交付内容   | 视频、集锦；数据另购       | 视频 + 模块化数据       | 视频 + 比赛分析                    | **球员跑动 / 速度 / 热图 + 足球轨迹** |
| 目标客户   | 俱乐部、学校、联赛        | 职业与半职业           | 俱乐部、联赛、转播                    | **青训、校园、业余与半职业**          |

**一句话结论**：在客户已经拥有摄像机的场景下，我们的进入成本是 **0 硬件 + 100 元/场**；Pixellot 同类单场分析约 **$55（约 390 元）**，Veo 还需先付约 **$1,999** 的硬件。**价格差约 4 倍，硬件门槛差一个数量级。**

### 6.3 壁垒：复现远比看起来难

**开源世界不缺"能跑"的足球分析代码，缺的是能稳定交付的。** 我们从零到可演示，用了 **47 次提交、9 条分支、7 个已合并 PR**。

真正的难点是**人和球在复杂场景下的稳定关联**——遮挡、换人、镜头移动、强光、球鞋与场边杂物混淆，每一个都会让结果散架。这不是我们一家的困境：

| 行业基准（Game State Reconstruction） | 成绩 |
|---|---|
| GSR 2025 冠军 · 检测指标 GS-DetA | **51.36** |
| GSR 2025 冠军 · 身份关联 GS-AssA | **79.55** |
| SoccerNet GSR 2024 基线 · GS-HOTA | 22.26% |

**在最前沿的学术评测里，把人和球稳定关联起来也只有一半左右水平。** 而这些指标依赖转播级多机位素材——单机位、非转播条件下的难度只会更高。

我们交出的实测结果：**45 条原始轨迹 → 20 个稳定球员身份，轨迹覆盖率 94.5%，足球检测 98.6%。**

**所以壁垒不在"选哪个模型"，而在于把检测、关联、标定、纠错、报告串成一条能交付的链路，并把长尾场景一个个啃下来。** 这部分工作不性感、不上论文，但它是客户真正愿意付钱的东西，也是竞品在几百元价位不愿意投入的部分。

## 八、风险与应对

| 风险 | 应对 |
|---|---|
| 机位过低导致远端球员像素不足 | 产品明确建议抬高机位（45° 以上）或单机位覆盖半场；标定与指标按实际机位给出适用区间 |
| 场地光照与白线条件差异 | 逐帧白线标定已处理强光过曝；极端条件下降级为人工标定 |
| 足球遮挡与出球瞬间 | 多帧联合筛选保留候选路径，缺失不插值；配合人工复核界面 |
| 客户场地无固定机位 | 提供手机/相机架设指引，按场收费模式降低客户决策成本 |
